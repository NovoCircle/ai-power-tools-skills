AI Power Tools for Sparx EA 3.6.3.

**A packaging and licensing release; the skills are unchanged apart from the release stamp.** 3.6.3 supersedes 3.6.2.

The license agreement is revised, and the license file and third-party notices now ship inside both the Claude Desktop
extension and the VS Code extension. Both configure screens link the agreement. No tool or skill changed.

## Installing and updating

Unchanged from 3.6.2: the server is the AI Power Tools for Sparx EA Claude Desktop extension
([`AI-Power-Tools-for-Enterprise-Architect.mcpb`](https://github.com/NovoCircle/ai-power-tools-releases/releases/latest/download/AI-Power-Tools-for-Enterprise-Architect.mcpb));
the skills are this plugin, from the `novocircle` marketplace on your claude.ai account. To update the skills, open
https://claude.ai/customize/plugins, choose **Manage marketplaces**, sync **novocircle**, then quit Claude Desktop
completely and reopen it. Update the extension too: the `ea-start-here` skill tells you when it is behind.
