AI Power Tools for Sparx EA 3.6.2.

**A server fix; the skills are unchanged apart from the release stamp.** 3.6.2 supersedes 3.6.1.

On the Claude Desktop extension, the server no longer advises `install_skills` (which would load every skill
twice in the Code tab, beside this plugin). If an older installer left skill copies in your user folder, the server
lists them and says how to remove them.

## Installing and updating

Unchanged from 3.6.1: the server is the AI Power Tools for Sparx EA Claude Desktop extension
([`AI-Power-Tools-for-Enterprise-Architect.mcpb`](https://github.com/NovoCircle/ai-power-tools-releases/releases/latest/download/AI-Power-Tools-for-Enterprise-Architect.mcpb));
the skills are this plugin, from the `novocircle` marketplace on your claude.ai account. To update the skills, open
https://claude.ai/customize/plugins, choose **Manage marketplaces**, sync **novocircle**, then quit Claude Desktop
completely and reopen it. Update the extension too: the `ea-start-here` skill tells you when it is behind.
