AI Power Tools for Sparx EA 3.6.1.

**The server is the Claude Desktop extension again; this plugin carries the skills.** 3.6.1 supersedes 3.6.0.

## Installing

1. Install the **AI Power Tools for Sparx EA** Claude Desktop extension, the MCP server:
   download [`AI-Power-Tools-for-Enterprise-Architect.mcpb`](https://github.com/NovoCircle/ai-power-tools-releases/releases/latest/download/AI-Power-Tools-for-Enterprise-Architect.mcpb),
   open Claude Desktop **Settings > Extensions**, drag the file in and click **Install**.
2. Add the skills on your claude.ai account: open https://claude.ai/customize/plugins, choose
   **Add marketplace**, enter `NovoCircle/ai-power-tools-skills`, and install **AI Power Tools**.
3. Quit Claude Desktop completely and reopen it. The skills then load in Claude Desktop chat,
   Claude Cowork and the Code tab.

## Updating

Open https://claude.ai/customize/plugins, choose **Manage marketplaces**, and sync **novocircle**;
then quit Claude Desktop completely and reopen it. The marketplace does not update on its own.
The `ea-start-here` skill tells you at the start of a session when the skills or the server are
behind the current release.

## What changed

- **The plugin is skills only.** 3.6.0 carried the server inside the plugin; claude.ai refuses
  such a plugin and Claude Desktop chat never runs its server. **If you installed the 3.6.0
  plugin and removed the extension, install the extension again** (step 1).
- **`ea-start-here` checks versions.** Its preflight passes this release to the server, shows the
  server's update notice word for word, and says when the extension is missing or older than
  the skills.

## Requires

The AI Power Tools for Sparx EA extension (the server). The skills work with an older extension,
and `ea-start-here` tells you to update it. The bundle-wide floor for `install_skills` stays
server 3.6.0.
