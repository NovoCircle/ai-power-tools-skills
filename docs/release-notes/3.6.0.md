AI Power Tools for Sparx EA 3.6.0.

**Reporting from your model into Power BI, two Prolaborate skills, and a marketplace that serves only released builds.** 3.6.0 supersedes 3.5.0. It needs server 3.6.0, which the plugin installs with it.

## Installing

```
claude plugin marketplace add NovoCircle/ai-power-tools-skills
claude plugin install ai-power-tools@novocircle
```

Restart Claude afterwards — plugin changes are staged, not applied to a running session. If you already have the plugin, `claude plugin marketplace update novocircle` then `claude plugin update ai-power-tools@novocircle`, and restart.

## What's new

- **`ea-reporting-database`** builds a reporting layer for your repository: business tables named and shaped by the technology that governs the model — one per stereotype with its tags as columns, one per connector combination the technology allows, and a Table Directory. It builds them as SQL views inside the EA database, as a separate SQL Server reporting database, or as Parquet files, and checks every cell against an independent read through EA.
- **`ea-power-bi`** generates a complete Power BI project (`.pbip`, TMDL) over that reporting layer, with the relationships declared and EA's own tables hidden.
- **`prol-impact-analysis`** and **`prol-matrix`** work with Prolaborate: tracing dependencies through Analyzer views, and reading, filtering, sharing and exporting relationship matrices.
- **Icons from the libraries EA already ships.** The modeling skills now route "put an icon on this element" to `find_icon` and `set_element_icon`.

## The marketplace serves released builds only

The marketplace entry now pins the plugin to the released tree for this version (`ai-power-tools-releases`, tag `v3.6.0`, by commit). Development on this repository no longer reaches anyone's install. Nothing changes in the commands you run.

## Requires server 3.6.0

The bundle-wide floor is server 3.6.0, and the floor is all or nothing. The plugin installs the matching server, so plugin users need do nothing. A server below 3.6.0 that still uses `install_skills` receives no files and an error naming the version it needs.

## Enterprise deployment

Pin the managed-settings marketplace to this release:

```json
{
  "extraKnownMarketplaces": {
    "novocircle": {
      "source": {
        "source": "github",
        "repo": "NovoCircle/ai-power-tools-skills",
        "ref": "v3.6.0"
      }
    }
  },
  "enabledPlugins": {
    "ai-power-tools@novocircle": true
  }
}
```

Full detail in `docs/enterprise-deployment.md`.

## Fixes

- Several skill instructions named an operation on the wrong tool, a parameter the server does not take, or a response shape it does not return. Each is corrected against the 3.6.0 server.
- `ea-mdg-assess` now says what its ad hoc count measures: elements across the whole repository whose stereotype no loaded technology defines.
- Examples that use the Westbrook Bank reference model are presented as illustrations to substitute with your own technology, stereotypes and model.

## Verifying an install

```
claude plugin list
claude plugin details ai-power-tools
```

Expect `ai-power-tools@novocircle` enabled at 3.6.0, with the skills listed and the MCP server present.
