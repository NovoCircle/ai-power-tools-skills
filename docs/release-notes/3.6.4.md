AI Power Tools for Sparx EA 3.6.4.

**Diagram descriptions and manifests, a reporting database in Microsoft Fabric, Power BI models ready for Microsoft
365 Copilot, and VS Code setup.** These skills need AI Power Tools for Sparx EA 3.6.4: update the extension along with
the skills.

## What's new

- **Diagram descriptions.** `ea-import-export` and `ea-stakeholder-reporting` can write a plain-language description
  into each diagram's Notes, audit which descriptions are current, out of date, missing or edited, and refresh them
  without discarding edits a person made. A diagram that is open in EA with unsaved changes is never written.
- **Diagram and package manifests.** One call reads a whole diagram, or every diagram in a package, with everything
  another tool needs to redraw or describe it. This is now the recommended way to take a diagram to another tool.
- **A reporting database in Microsoft Fabric.** `ea-reporting-database` can build the reporting database in a SQL
  database in Microsoft Fabric with Microsoft Entra sign-in. You sign in once per server process, and the Power BI
  refresh needs no gateway.
- **Power BI models that work better with Microsoft 365 Copilot.** `ea-power-bi` now gives every business table,
  column and measure a description, takes business terms from a definitions file you approve, adds a count measure to
  each entity table, adds an Overview page to new projects, and hides key columns. The Parquet step reports the model's
  size and warns when it passes 1,000 tables plus columns.
- **Microsoft's Power BI Modeling MCP server.** `ea-power-bi` explains how to use it from Claude alongside AI Power
  Tools.
- **When the server is missing.** If the AI Power Tools server is not in the session, the skills say why that usually
  happens and how to fix it, instead of failing on the first call.
- **Prolaborate in any browser.** The Prolaborate skills work with whichever browser control your client offers.

## Changes you may notice

- When an existing Power BI project is regenerated, duplicate relationship names now get a suffix only, so some
  relationship names can differ from the previous generation. Existing visuals keep working.
- Six key columns are now hidden in generated models (`ea_guid`, `source_guid`, `target_guid`, `connector_guid`,
  `connector_id`, `property_id`). Visuals that use them keep working.
- Generated models now include count measures. Earlier guidance said not to add them.
- Path B refuses DirectQuery for a reporting database source. The project it used to produce did not work.

## Installing and updating

The server is the AI Power Tools for Sparx EA Claude Desktop extension
([`AI-Power-Tools-for-Enterprise-Architect.mcpb`](https://github.com/NovoCircle/ai-power-tools-releases/releases/latest/download/AI-Power-Tools-for-Enterprise-Architect.mcpb));
the skills are this plugin, from the `novocircle` marketplace on your claude.ai account. To update the skills, open
https://claude.ai/customize/plugins, choose **Manage marketplaces**, sync **novocircle**, then quit Claude Desktop
completely and reopen it. In VS Code, the AI Power Tools extension now offers to set up the skills, and
**EA: Check for Updates** reports whether they are current.
